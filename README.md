# 🇨🇳 中华人民共和国超级计算器 v1.1

**代号: 红龙** 🐉

---

## 🧮 简介

一款完全中文化界面的超级计算器 для Windows.  
Ввод и вывод — только китайские цифры (一, 二, 三…).  
Интерфейс построен на нативных Win32-виджетах через библиотеку `lxn/walk`.

**Пример:**

```
   一二三   (123)
+ 四五六   (456)
= 五七九   (579)
```

---

## 🚀 Быстрый старт

### Способ 1 — готовый бинарник

```bash
cd dist/
.\CPP-calc.exe
```

### Способ 2 — сборка из исходников

```bash
# Требуется: Go 1.21+, MinGW-w64 (gcc) для CGO
go build -o CPP-calc.exe .\cmd\calculator\
.\CPP-calc.exe
```

## 🎮 Использование

### Кнопки

| Кнопка | Действие |
|--------|----------|
| **七** **八** **九** … **零** | Ввод китайских цифр |
| **＋** | Сложение |
| **−** | Вычитание |
| **×** | Умножение |
| **÷** | Деление |
| **＝** | Вычислить |
| **清除** | Сброс всего |
| **←** | Удалить последний символ |
| **．** | Десятичная точка |

### Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| `+` `-` `*` `/` | Операторы |
| `0`–`9` | Ввод арабских цифр (авто-конвертация в китайские) |
| `一`–`九` | Прямой ввод китайских цифр |
| `Enter` | = |
| `Backspace` | ← |
| `Escape` | 清除 |

### 🚩 Режим председателя

Кнопка **主席** — интерфейс становится полностью красным,
появляется портрет **Мао Цзэдуна** и играет гимн **«Красное солнце в небе»** (东方红).

## 🔧 Технические детали

| Компонент | Технология |
|-----------|------------|
| **Язык** | Go 1.26 (module: `calculator`) |
| **GUI** | `github.com/lxn/walk` — нативные Win32控件ы |
| **Аудио** | `winmm.dll` (MCI) — открытие/воспроизведение MP3 |
| **Окно** | `user32.dll` — позиционирование по центру экрана |
| **DPI** | `shcore.dll` — `SetProcessDpiAwareness` (чёткий UI на HiDPI) |
| **Ресурсы** | `embed.FS` — PNG и MP3 встроены в .exe |
| **Сборка** | `go build` (требует CGO + MinGW-w64) |
| **Архитектура** | Модульная (8 пакетов) |

### Системные требования

| Требование | Примечание |
|------------|------------|
| **OS** | Windows 7/10/11 (только x64) |
| **Go** | 1.21+ (для сборки) |
| **MinGW-w64** | Необходим для CGO (при сборке) |
| **Зависимости** | `golang.org/x/sys`, `lxn/walk`, `lxn/win` |
